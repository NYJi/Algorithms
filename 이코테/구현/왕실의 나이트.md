# 📖 이코테 구현 예제(4-3)
## 📌 문제 정의
  
행복 왕국의 왕실 정원은 체스판과 같은 8 × 8 좌표 평면이다. 왕실 정원의 특정한 한 칸에 나이트가 서 있다.</br>
나이트는 매우 충성스러운 신하로서 매일 무술을 연마한다.</br>
나이트는 말을 타고 있기 때문에 이동을 할 때는 L자 형태로만 이동할 수 있으며 정원 밖으로는 나갈 수 없다.</br>
나이트는 특정한 위치에서 다음과 같은 2가지 경우로 이동할 수 있다.

</br>


**1. 수평으로 두 칸 이동한 뒤에 수직으로 한 칸 이동하기**</br>
**2. 수직으로 두 칸 이동한 뒤에 수평으로 한 칸 이동하기**


<img width="411" height="385" alt="image" src="https://github.com/user-attachments/assets/06ce8268-0fbf-4670-8f76-65205f9f4ae3" />


  이처럼 8 × 8 좌표 평면상에서 나이트의 위치가 주어졌을 때 나이트가 이동할 수 있는 경우의 수를 출력하는 프로그램을 작성하시오.</br>
  이때 왕실의 정원에서 행 위치를 표현할 때는 1부터 8로 표현하며, 열 위치를 표현할 때는 a부터 h로 표현한다.
  
  </br>

### 입력
- 첫째 줄에 8*8 좌표 평면상에서 현재 나이트가 위치한 곳의 좌표를 나타내는 두 문자로 구성된 문자열이 입력된다.</br>
  입력 문자는 a1처럼 열과 행으로 이뤄진다.

### 출력
- 첫째 줄에 나이트가 이동할 수 있는 경우의 수를 출력하시오.

### 테스트 예시
|입력|출력|
|---|---|
|a1|2|
</br>

## 📌 나의 풀이
~~~python
#왕실의 나이트

#조건
'''
1. 수평으로 2칸 이동 후, 수직 1칸 --> (오른쪽 2칸 위, 아래) (왼쪽 2칸 위, 아래)
(-1, 2), (1, 2), (1,-2) (-1, -2)


2. 수직으로 2칸 이동 후, 수평 1 칸 --> (위쪽2칸 오른쪽1, 위쪽 2칸 왼쪽1칸, 아래쪽 2칸 오른쪽 1칸, 아래쪽 2칸 왼쪽 1칸)
(-2, 1), (-2, -1), (2, 1), (2, -1)
'''

s = list(input())
dir_control = [[-1, 2], [1, 2],[1, -2], [-1, -2], [-2, 1], [-2, -1], [2, 1], [2, -1]]

#시작 포인트 초기화
s_point_y = (ord(s[0]) - 97) #열
s_point_x = int(s[1]) - 1 #행

cnt = 0

for i in dir_control:
    dir_x, dir_y = i

    px = s_point_x + dir_x
    py = s_point_y + dir_y
    
    #좌표 범위 벗어나면 continue, 그게 아니면 카운트 증가
    if px < 0 or py < 0 or px > 7 or py > 7:
        continue
    else:
        cnt += 1


print(cnt)
~~~

### 💡문제 분석
- 나이트가 움직일 수 있는 방향 8가지
- 알파벳을 숫자로 바꾸어 주기 (즉, 각각을 0,0으로 초기화) 혹은 1,1이 첫 시작 좌표로 해도 됨
  -  8*8에서 1,1로 기준을 하면 좌표 범위 벗어나는 기준을 x > 8, y > 8 이렇게 해주어야 함
