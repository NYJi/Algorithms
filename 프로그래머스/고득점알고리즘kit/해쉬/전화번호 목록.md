# 📖 프로그래머스 고득점 알고리즘kit
## 📌 문제 정의
전화번호부에 적힌 전화번호 중, 한 번호가 다른 번호의 접두어인 경우가 있는지 확인하려 합니다.
전화번호가 다음과 같을 경우, 구조대 전화번호는 영석이의 전화번호의 접두사입니다.

- 구조대 : 119
- 박준영 : 97 674 223
- 지영석 : 11 9552 4421

전화번호부에 적힌 전화번호를 담은 배열 phone_book 이 solution 함수의 매개변수로 주어질 때,</br>
어떤 번호가 다른 번호의 접두어인 경우가 있으면 false를 그렇지 않으면 true를 return 하도록 solution 함수를 작성해주세요.</br>

</br>

### 제한사항
- phone_book의 길이는 1 이상 1,000,000 이하입니다.
  - 각 전화번호의 길이는 1 이상 20 이하입니다.
  - 같은 전화번호가 중복해서 들어있지 않습니다.
</br>

### 출력
|phone_book|	return|
|---|---|
|["119", "97674223", "1195524421"]	|false|
|["123","456","789"]	|true|
|["12","123","1235","567","88"]	|false|

- **입출력 예 #1**</br>
앞에서 설명한 예와 같습니다.

- **입출력 예 #2**</br>
한 번호가 다른 번호의 접두사인 경우가 없으므로, 답은 true입니다.

- **입출력 예 #3**</br>
첫 번째 전화번호, “12”가 두 번째 전화번호 “123”의 접두사입니다. 따라서 답은 false입니다.


</br>

## 📌 나의 풀이
~~~python
def solution(phone_book):
    
    phone_book.sort() #정렬을 함으로서, 
    
    for i in range(len(phone_book)-1): 
        if phone_book[i+1].startswith(phone_book[i]):  #특정 문자열.startswith("원하는 시작 문자열 패턴") --> 시작 문자열 패턴을 특정 문자열에서 시작하는지 확인
            return False
    return True
                
~~~

### 💡문제 분석
- 접두사가 일치하는 확인!  
  - phone_book을 정렬함으로써, 숫자패턴의 문자열을 확인할때 왔다갔다 비교 안해도 됌!
