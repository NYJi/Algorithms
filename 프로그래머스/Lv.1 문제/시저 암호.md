## 📌 문제 정의
어떤 문장의 각 알파벳을 일정한 거리만큼 밀어서 다른 알파벳으로 바꾸는 암호화 방식을 시저 암호라고 합니다.</br>
예를 들어 "AB"는 1만큼 밀면 "BC"가 되고, 3만큼 밀면 "DE"가 됩니다.</br>
"z"는 1만큼 밀면 "a"가 됩니다. 문자열 s와 거리 n을 입력받아 s를 n만큼 민 암호문을 만드는 함수, solution을 완성해 보세요.</br>
</br>

### 제한사항
- 공백은 아무리 밀어도 공백입니다.
- s는 알파벳 소문자, 대문자, 공백으로만 이루어져 있습니다.
- s의 길이는 8000이하입니다.
- n은 1 이상, 25이하인 자연수입니다.

## 📌 나의 풀이
~~~python
lower_alph = 'abcdefghijklmnopqrstuvwxyz'
upper_alph = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'


def alph_index_calculate(alph_lst, i, n):
    alph_index = (alph_lst.find(i) + n) % 26 # n만큼 밀었을 때 해당하는 알파벳의 인덱스 값 (25의 나머지 값에 해당하는 인덱스 값; 맨끝에서 밀면 다시 0인덱스로 초기화 해야하기 때문)
    
    return alph_lst[alph_index] #인덱스에 해당하는 알파벳을 리턴 후 answer에 더하기!
    

def solution(s, n):
    answer = ''
    
    for i in s:
        if i == ' ':
            answer += i
            
        else:
            if ord(i) > ord('Z'):
                answer += alph_index_calculate(lower_alph, i, n)
                
            else:
                answer += alph_index_calculate(upper_alph, i, n)
            
    
    return answer
~~~
