## 📌 문제 정의
0과 1로 이루어진 어떤 문자열 x에 대한 이진 변환을 다음과 같이 정의합니다.</br>

- x의 모든 0을 제거합니다.
- x의 길이를 c라고 하면, x를 "c를 2진법으로 표현한 문자열"로 바꿉니다.
  
예를 들어, x = "0111010"이라면, x에 이진 변환을 가하면 x = "0111010" -> "1111" -> "100" 이 됩니다.</br>

0과 1로 이루어진 문자열 s가 매개변수로 주어집니다. s가 "1"이 될 때까지 계속해서 s에 이진 변환을 가했을 때,</br>
이진 변환의 횟수와 변환 과정에서 제거된 모든 0의 개수를 각각 배열에 담아 return 하도록 solution 함수를 완성해주세요.</br>

</br>

### 제한사항
- s의 길이는 1 이상 150,000 이하입니다.
- s에는 '1'이 최소 하나 이상 포함되어 있습니다.


</br>

### 출력

|s	|result|
|---|---|
|"110010101001"	|[3,8]|
|"01110"|	[3,3]|
|"1111111"|	[4,1]|

</br>

## 📌 나의 풀이
~~~python
def solution(s):
    answer = []
    cnt = 1
    zero_cnt = 0
    
    while True:
        c = s.count('1')# 0을 뺀 길이
        x = format(c,'b') # 이진 변환 결과
        zero_cnt += (s.count('0')) #s 업데이트 전에 먼저 0갯수 카운
    
        if int(x) > 1: # 이진 변환 결과가 1이 아니면
            s = str(x) # s를 이진변환 결과로 업데이트
            cnt += 1 #다음 회차로 넘어감 (1 추가)
        else:
            break
    
    answer.append(cnt)
    answer.append(zero_cnt)

    return answer

~~~
### 💡문제 분석
- 문자열 s에서 0을 뺀 문자열의 길이를 구하고, 이를 이진 변환을 진행
- 만약, 이진 변환 결과가 1이 아니면 s를 해당 결과로 업데이트 후 다시 위에 과정 반복
